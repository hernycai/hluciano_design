## 📤 Pasos para Subir a GitHub y Publicar en Vercel

### Paso 1: Subir el proyecto a GitHub

1. Abre tu terminal en la carpeta del proyecto:
   ```bash
   cd "/Users/hernanluciano/Desktop/HLuciano Design"
   ```
2. Inicializa el repositorio Git:
   ```bash
   git init
   git add .
   git commit -m "feat: landing page profesional de Hernan Luciano con QA y Mascota Virtual"
   ```
3. Crea un nuevo repositorio en tu cuenta de GitHub [github.com/hernycai](https://github.com/hernycai) (por ejemplo `hluciano-design` o `portfolio`).
4. Vincula tu repositorio remoto y sube los cambios:
   ```bash
   git branch -M main
   git remote add origin https://github.com/hernycai/hluciano_design.git
   git push -u origin main
   ```

---

### Paso 2: Publicar en Vercel (Gratis y Automático)

1. Ingresa a [vercel.com](https://vercel.com) e inicia sesión con tu cuenta de **GitHub**.
2. Haz clic en **"Add New..."** ➔ **"Project"**.
3. Selecciona tu repositorio recién creado (`hluciano_design`) y presiona **"Import"**.
4. Deja la configuración por defecto (Framework Preset: *Other*) y haz clic en **"Deploy"**.
5. ¡Listo! En menos de 30 segundos tu web estará online con certificado SSL gratuito (HTTPS) y URL personalizada.
